# Mikonus Support

Welcome to the official support and feedback repository for Mikonus.

This repository does not contain the Mikonus source code. It is used for support, bug reports, device compatibility and feature requests.

## 🐛 Found a bug?

Create a **Bug Report** and describe what happened.

## 🏠 Smart-home device not working correctly?

Create a **Device Compatibility** report.

Please include the manufacturer, model and available capabilities if possible. This information helps improve device support in Mikonus.

## ✨ Have an idea?

Create a **Feature Request**.

Suggestions and ideas for improving Mikonus are always welcome.

## 💬 Need help?

Use **Discussions → Q&A** if you have a question about using Mikonus.
